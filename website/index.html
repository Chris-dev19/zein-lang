Zein

Learn Once, Practice Forever

A minimal, statically-typed language with Go-like syntax, Hindley-Milner inference, and mutation — compiles to JavaScript. No runtime, no shim, just Node.js.

Why Zein? Get Started

Why Zein?

Most programming languages ask you to choose between two tradeoffs:

Powerful but complex

Languages like Rust, C++, and Haskell are incredibly capable, but they take months or years to master. The cognitive overhead of lifetimes, templates, or monads gets in the way of writing simple programs. You spend more time fighting the language than solving your problem.

Simple but opaque

Languages like Python and JavaScript are easy to start with, but they hide how the computer works. There's no compiler to catch mistakes — you find bugs at runtime. You never learn how a language is implemented because the implementation is millions of lines of C code.

Zein is neither. It's a real, typed, compiled language that you can understand completely — every part of it, from tokenizer to code generator — in a single afternoon.

The name comes from zen — simplicity, clarity, focus. Every feature in Zein exists because it's needed. Nothing more.

Why not just use Go? Or Elm? Or OCaml?

Go is simple but its type system is weak — no generics (or recently added but clunky), no algebraic types, no inference. Elm is elegant but tied to a UI framework and has no mutation. OCaml is powerful but its syntax is unfamiliar and its ecosystem is niche.

Zein takes the best ideas and distills them:

  • Go's syntax — braces, types after names, no semicolons. Familiar from the start.
  • Hindley-Milner inference — like Elm, OCaml, Haskell. Types are inferred, never in your way.
  • Algebraic data types + pattern matching — like Rust, OCaml, Haskell. Express complex data naturally.
  • Mutable by default — like Go. No mut noise. Just reassign.
  • Compiles to clean JS — run anywhere Node runs. No VM, no runtime, no dependencies.
The whole compiler is ~3000 lines of Gleam code. Read it. Modify it. Learn how compilers work by working on one.

Who is Zein for?

Students learning compilers

Read every phase — lexing, parsing, type inference, code generation — in one sitting.

Hobbyists who want a language they own

Not someone else's 20-year-old codebase. A language you can actually finish.

Teachers looking for a classroom language

Small enough to teach in a semester. Practical enough to write real programs.

Anyone tired of over-engineered tools

Zein prioritizes simplicity over everything. If a feature doesn't pull its weight, it's removed.

Philosophy & Goals

Zein was designed around a few core beliefs about what a programming language should be.

Design Principles

Minimal core

If, for, while, match, pipe, return, records, lists — everything else is a library. Every feature must earn its place.

Mutable by default

No mut keyword. No immutability dogma. Variables are just boxes — put a new value in when you need to.

Static typing, inferred

Hindley-Milner type inference means you get the safety of static types without writing them. The compiler figures it out.

No runtime

Zein compiles to bare JavaScript. No VM, no garbage collector shim, no standard library to import. The output is readable JS.

Transparent compilation

The generated JS looks like what you'd write by hand. You can learn how a compiler works by reading its output.

Go-like syntax

Braces, types after names, no semicolons. Syntax is the least interesting part of a language — use one everyone already knows.

Goals

Educational

A language you can understand completely. The entire compiler is readable in a few hours. No black boxes.

Practical

Write real scripts, solve real problems, with real type safety. Not a toy — a tool you can use daily.

Minimal

Fit the entire language spec in your head. No features you don't use. No surprises.

Approachable

Like Go — you can be productive in an afternoon. Unlike Go — with full HM type inference and algebraic types.

Benefits

BenefitWhy it matters
Understand the whole compiler~3000 lines of Gleam. Lexer, parser, typechecker, codegen — all in one project, all readable.

Non-goals

Zein is not trying to be:

  • A systems language (no manual memory management, no inline assembly)
  • A replacement for Python or JavaScript in production (no massive package ecosystem)
  • A research language (no dependent types, no effect systems, no theorem proving)
  • A language you build a FAANG-scale backend with (not yet, anyway)

Zein is a language for learning, teaching, and small-to-medium scripts. If that's what you need, it might be the nicest option available.

Quick Start

Create hello.zn:

Zein 
main {
  print("hello from Zein!")
}
$ zein hello.zn
hello from Zein!

Compile to JS without running:

$ zein --compile hello.zn

Language Tour

Imports & Standard Library

Import built-in modules with import. Currently available: random.

Zein 
import random

main {
  print(random_int(100))
  // prints a random int between 0 and 100
}

Standard library modules are built into the compiler. More modules coming soon.

Functions

Declare with fn or the shorthand name { body }. The last expression in a function is the return value. Type annotations are optional — everything is inferred.

Zein 
fn add(x: Int, y: Int) -> Int {
  x + y
}

// shorthand for fn main() { ... }
main {
  print(add(2, 3))
}

Variables

Bind with let. Type annotation optional. Variables are mutable by default.

Zein 
let x: Int = 5
let y = "inferred"

// reassign freely
x = 10

// blocks are expressions
let result = {
  let a = 1
  let b = 2
  a + b
}

Conditionals & else-if

if is an expression — it returns a value. Supports chained else if. The else branch is optional (returns Nil if omitted).

Zein 
fn grade(score: Int) -> String {
  if score >= 90 {
    "A"
  } else if score >= 80 {
    "B"
  } else if score >= 70 {
    "C"
  } else {
    "F"
  }
}
Zein 
// if as an expression
let msg = if is_ready { "go" } else { "wait" }

Loops

Zein has for-in loops (over lists/ranges) and while loops.

For-in loop

Zein 
for i in 1..5 {
  print(i)
}

// over a list
let names = ["Alice", "Bob", "Eve"]
for name in names {
  print(name)
}

While loop

Zein 
let x = 0
while x < 5 {
  print(x)
  x = x + 1
}
Note: while is a statement — it returns Nil. Use for when iterating over collections.

Records

Records are anonymous structs — create them with TypeName(field: value) syntax. They compile to plain JS objects.

Zein 
fn main {
  let person = Person(name: "Alice", age: 30)
  print(person.name)
  print(person.age)
}
Tip: Records use named fields like Person(name: "Alice", age: 30). Access fields with dot syntax person.name.

Arrays (Lists)

Lists are ordered, homogeneous collections. Use bracket syntax with optional trailing comma.

Zein 
let empty = []
let numbers = [1, 2, 3, 4, 5]
let mixed = ["a", "b", "c"]

print(numbers[0])  // index access

for x in numbers {
  print(x)
}
Note: Lists are type-homogeneous — [1, "a"] is a type error. Index access uses list[index] syntax.

Methods & Field Access

Call methods and access fields on any value with dot syntax. Compiles directly to JS property access and method calls.

Zein 
let s = "hello"

// field access
print(s.length)

// method call
print(s.toUpperCase())
print(s.toLowerCase())

// chaining
print("  hello  ".trim().toUpperCase())
Tip: Since Zein compiles to JS, any JS String, Array, or object method is available via dot syntax.

Pattern Matching

match destructures values with patterns. The wildcard _ matches anything. Guards are supported with if.

Zein 
fn describe(n: Int) -> String {
  match n {
    1 -> "one"
    2 -> "two"
    _  -> "other"
  }
}

match opt {
  Some(val) -> print(val)
  None     -> print("nothing")
}

Pipe Operator

|> pipes the left value as the first argument to the function on the right.

Zein 
fn double(x: Int) -> Int { x * 2 }

fn main {
  5 |> double |> print
  // same as: print(double(5))
}

Lambdas

Zein 
let increment = fn(x: Int) { x + 1 }
print(increment(5))  // 6

fn apply(f, x) { f(x) }
print(apply(fn(n) { n * 2 }, 3))  // 6

Built-ins

print accepts any type, prints via console.log, returns Nil.

Zein 
print("hello")
print(42)
print(3.14)
print("hello " <> name)

Showcase

Complete Zein programs demonstrating real usage patterns.

FizzBuzz 
fn fizzbuzz(n: Int) -> String {
  if n % 15 == 0 {
    "FizzBuzz"
  } else if n % 3 == 0 {
    "Fizz"
  } else if n % 5 == 0 {
    "Buzz"
  } else {
    int.to_string(n)
  }
}

main {
  for i in 1..20 {
    print(fizzbuzz(i))
  }
}
Collatz 
fn collatz(n: Int) {
  let x = n
  while x > 1 {
    if x % 2 == 0 {
      x = x / 2
    } else {
      x = 3 * x + 1
    }
    print(x)
  }
}

main { collatz(27) }
Person Records 
fn greet(person) {
  "Hi, I'm " <> person.name
  <> " and I'm "
  <> int.to_string(person.age)
}

main {
  let alice = Person(
    name: "Alice",
    age: 30,
  )
  print(greet(alice))
}
List Ops 
fn sum(xs: List(Int)) -> Int {
  let total = 0
  for x in xs { total = total + x }
  total
}

main {
  let nums = [1, 2, 3, 4, 5]
  print(sum(nums))
  print(nums[0])
  print(nums.length)
}
Grade Calculator 
type Grade { A B C D F }

fn to_grade(score: Int) -> Grade {
  if score >= 90 { A }
  else if score >= 80 { B }
  else if score >= 70 { C }
  else if score >= 60 { D }
  else { F }
}

main {
  let scores = [95, 82, 73, 58, 100]
  for score in scores {
    print(to_grade(score))
  }
}
String Methods 
main {
  let text = "  Hello, Zein World!  "

  print(text.trim())
  print(text.trim().toLowerCase())
  print(text.trim().split(" "))
  print(text.trim().startsWith("Hello"))
  print(text.trim().length)
}

VS Code Integration

Install the extension for syntax highlighting, live diagnostics, and autocomplete:

$ code --install-extension zein-lang-0.1.0.vsix

Features:

  • Syntax highlighting — TextMate grammar for .zn files
  • Live diagnostics — tokenizer, parser, and type errors shown inline
  • Smart autocomplete — snippets for fn, if, match, for, while, print(), and more
  • Identifier completion — functions, types, and variables defined in the current file
