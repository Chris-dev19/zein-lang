Zein

Learn Once, Practice Forever

A minimal, statically-typed language with Go-like syntax, garbage collection, and mutation — compiles to JavaScript. No runtime, no shim, just Node.js.

Get Started

Install

Zein is built from source. You need Node.js 18+ and Gleam 1.17+ (which requires Erlang/OTP 27+).

$ git clone https://github.com/zein-lang/zein && cd zein && ./install.sh

The script detects your distro and installs dependencies:

DistroCommandDependencies
Debian / Ubuntu sudo apt install erlang nodejs gleam Erlang/OTP, Node.js, Gleam
Fedora sudo dnf install erlang nodejs gleam Erlang/OTP, Node.js, Gleam
Arch Linux sudo pacman -S erlang nodejs gleam Erlang/OTP, Node.js, Gleam
NixOS nix profile install nixpkgs#erlang nixpkgs#nodejs nixpkgs#gleam Erlang/OTP, Node.js, Gleam
macOS brew install erlang nodejs gleam Erlang/OTP, Node.js, Gleam

After install, compile and run a file:

$ zein hello.zn

Quick Start

Create a file hello.zn:

Zein 
fn main() {
  print("hello from Zein!")
}
$ zein hello.zn
hello from Zein!

Compile to JS without running:

$ zein --compile hello.zn

Language Tour

Comments

Zein 
// this is a comment
// comments start with // and go to end of line

Functions

Functions are declared with fn. Parameters use name: Type syntax. The return type is optional — if omitted, it's inferred.

Zein 
fn greet(name: String) -> String {
  "hello " <> name
}

// return type inferred
fn add(x: Int, y: Int) {
  x + y
}

// last expression is the return value
fn factorial(n: Int) -> Int {
  if n <= 1 { 1 } else { n * factorial(n - 1) }
}

Variables

Bind with let. Type annotation is optional. Variables are mutable by default — reassign freely.

Zein 
let x: Int = 5
let y = "inferred"

// mutable — reassign freely
x = 10

// blocks are expressions
let result = {
  let a = 1
  let b = 2
  a + b
}

Conditionals

if is an expression — it returns a value. The else branch is required.

Zein 
fn sign(n: Int) -> String {
  if n > 0 { "positive" } else {
    if n < 0 { "negative" } else { "zero" }
  }
}

// condition can be any Bool expression
let msg = if is_ready { "go" } else { "wait" }

Pattern Matching

match destructures values with patterns. The wildcard _ matches anything.

Zein 
fn describe(n: Int) -> String {
  match n {
    1 -> "one"
    2 -> "two"
    _  -> "other"
  }
}

match opt {
  Some(val) -> print(val)
  None     -> print("nothing")
}

Loops & Ranges

Zein 
// for loop with range
for i in 1..5 {
  print(i)
}

// ranges: start..end (inclusive)
let r = 0..10

Pipe Operator

The |> operator pipes the left value as the first argument to the function on the right.

Zein 
fn double(x: Int) -> Int { x * 2 }

fn main() {
  5 |> double |> print
  // same as: print(double(5))
}

Lambdas

Zein 
let increment = fn(x: Int) { x + 1 }
print(increment(5))  // 6

Print

print is a built-in function that accepts any type and prints it to stdout via console.log. It returns Nil.

Zein 
print("hello")       // String
print(42)              // Int
print(3.14)            // Float
print(True)            // Bool
print("hello " <> name) // expression

VS Code Integration

Install the extension for syntax highlighting, live diagnostics, and autocomplete:

$ code --install-extension zein-lang-0.1.0.vsix

Or via the VS Code UI: Extensions → ... → Install from VSIX.

Features:

  • Syntax highlighting — TextMate grammar for .zn files
  • Live diagnostics — tokenizer and type errors shown inline
  • Autocomplete — keywords, types, and identifiers in the file

Philosophy

Minimal core

If, for, match, pipe, return, range — everything else is a library.

Mutable by default

No mut keyword. Just reassign.

Garbage collected

You never think about memory. Always GC.

Static typing

Hindley-Milner type inference. Write less, catch more.

Go-like syntax

Braces, types after names, familiar structure.

Compiles to JS

Run anywhere Node.js runs. No runtime needed.
